F-test paper DGP API

Configurations, profile catalogs, reusable factories, and one-draw functions

Code 
import inspect

import pypanelsim as pps


def show_signature(object_):
    print(f"{object_.__name__}{inspect.signature(object_)}")

1 Catalogs

Code 
print(pps.available_ftest_temporal_designs())
print(pps.available_ftest_cohort_designs())
('constant', 'linear', 'concave', 'positive_then_negative', 'exponential', 'sinusoidal', 'random_walk')
('homogeneous', 'log_vs_linear_vs_sin', 'small_differences', 'large_differences', 'selection_on_gains', 'novelty_effects', 'activity_bias')

The first tuple contains the seven single-cohort temporal laws. The second contains all seven across-cohort experiments in the manuscript, including novelty_effects.

2 FTestTemporalConfig

Code 
show_signature(pps.FTestTemporalConfig)
FTestTemporalConfig(n_units: 'int' = 1000, n_periods: 'int' = 35, adoption_period: 'int' = 15, n_treated: 'int | None' = None, max_effect: 'float' = 1.0, unit_effect_scale: 'float' = 5.0, time_effect_scale: 'float' = 2.0, unit_trend_scale: 'float' = 0.01, noise_scale: 'float' = 2.0, error_rho: 'float' = 0.7) -> None

Controls unit and period counts, the single adoption period and treated count, effect scale, additive fixed-effect scales, unit-trend scale, and stationary AR(1) error parameters. n_treated=None means half the units. The default \(N=1{,}000\) is interactive; the paper uses \(N=50{,}000\).

Derived properties are treated_count and dimensions.

3 FTestCohortConfig

Code 
show_signature(pps.FTestCohortConfig)
FTestCohortConfig(n_units: 'int' = 1000, n_periods: 'int' = 30, adoption_periods: 'tuple[int, int, int]' = (10, 15, 20), cohort_shares: 'tuple[float, float, float]' = (0.125, 0.25, 0.125), unit_effect_scale: 'float' = 2.0, time_effect_scale: 'float' = 1.0, noise_scale: 'float' = 1.0, unit_error_rho: 'float' = 0.8, time_error_rho: 'float' = 0.2, periodic_time_effects: 'tuple[float, ...]' = (-0.1, 0.1, 0.0, 0.0, 0.1, 0.5, 0.5)) -> None

Controls the three adoption periods and cohort shares, panel dimensions, additive fixed-effect and noise scales, unit and time AR coefficients, and the periodic calendar-effect vector. cohort_sizes floors each share times n_units; dimensions returns the generic panel shape. Defaults reproduce the paper’s \((10,15,20)\) schedule and \((1/8,1/4,1/8)\) shares with a smaller interactive unit count. The paper uses \(N=20{,}000\).

4 Effect profiles

Code 
show_signature(pps.ftest_temporal_profile)
show_signature(pps.ftest_cohort_profiles)
ftest_temporal_profile(name: 'str', *, config: 'FTestTemporalConfig | None' = None, seed: 'int | np.random.SeedSequence | None' = None, rng: 'np.random.Generator | None' = None) -> 'np.ndarray'
ftest_cohort_profiles(name: 'str', *, config: 'FTestCohortConfig | None' = None) -> 'MappingProxyType[int, np.ndarray]'

ftest_temporal_profile() returns one read-only post-adoption vector. Supply seed= or rng= for a reproducible random_walk; deterministic paths do not consume it. ftest_cohort_profiles() returns a read-only mapping from adoption period to a read-only post-adoption vector.

The paths are ordinary inputs to the generic effect component:

Code 
config = pps.FTestCohortConfig(n_units=200)
profiles = pps.ftest_cohort_profiles("activity_bias", config=config)
effect = pps.CohortEventTimeEffect(profiles)

5 Reusable simulator factories

Code 
show_signature(pps.ftest_temporal_design)
show_signature(pps.ftest_cohort_design)
ftest_temporal_design(name: 'str', *, config: 'FTestTemporalConfig | None' = None, profile_seed: 'int | np.random.SeedSequence | None' = 42) -> 'PanelSimulator'
ftest_cohort_design(name: 'str', *, config: 'FTestCohortConfig | None' = None) -> 'PanelSimulator'

Both return PanelSimulator. ftest_temporal_design() accepts a separate profile_seed so the random-walk truth can remain fixed while repeated panel draws vary. The cohort factory uses exact fixed-size randomized cohorts.

Code 
simulator = pps.ftest_cohort_design(
    "log_vs_linear_vs_sin",
    config=config,
)
panel = simulator.simulate(seed=42)

6 One-draw functions

Code 
show_signature(pps.ftest_temporal)
show_signature(pps.ftest_cohort)
ftest_temporal(name: 'str', *, config: 'FTestTemporalConfig | None' = None, profile_seed: 'int | np.random.SeedSequence | None' = 42, seed: 'int | np.random.SeedSequence | None' = None, rng: 'np.random.Generator | None' = None) -> 'PanelDataset'
ftest_cohort(name: 'str', *, config: 'FTestCohortConfig | None' = None, seed: 'int | np.random.SeedSequence | None' = None, rng: 'np.random.Generator | None' = None) -> 'PanelDataset'

These create the corresponding simulator and immediately call simulate(). They accept the same configuration plus the standard mutually exclusive seed= and rng= arguments.
