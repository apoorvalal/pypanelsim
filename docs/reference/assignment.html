Assignment, feature, and effect API

Configuration, probability laws, metadata, and validation

Code 
import inspect

import numpy as np
import pypanelsim as pps


def show_signature(object_):
    print(f"{object_.__name__}{inspect.signature(object_)}")

1 GaussianUnitFeatures

Code 
show_signature(pps.GaussianUnitFeatures)
GaussianUnitFeatures(n_observables: 'int' = 2, n_unobservables: 'int' = 2) -> None

Draws independent standard-normal observables and unobservables matrices.

Parameter Default Contract
n_observables 2 Nonnegative feature count
n_unobservables 2 Nonnegative latent-feature count

Metadata includes kind="gaussian_unit_features", observable_names, and unobservable_names. A zero count returns an (n_units, 0) matrix without consuming draws for that block.

2 SingleCohortAssignment

Code 
show_signature(pps.SingleCohortAssignment)
SingleCohortAssignment(n_treated: 'int' = 40, adoption_period: 'int' = 40, treated_units: 'tuple[int, ...] | None' = None) -> None

Creates one deterministic absorbing cohort.

Parameter Default Contract
n_treated 40 Between one and n_units
adoption_period 40 Zero-based valid period
treated_units None Optional unique tuple of exactly n_treated valid positions

When positions are omitted, the last n_treated rows are treated. The model does not consume random draws. Metadata records the positions and adoption period.

3 RandomizedSingleCohortAssignment

Code 
show_signature(pps.RandomizedSingleCohortAssignment)
RandomizedSingleCohortAssignment(n_treated: 'int', adoption_period: 'int', eligible_units: 'Sequence[int] | None' = None) -> None

Samples a fixed number of units without replacement, then treats them from a common adoption period onward.

Parameter Contract
n_treated Positive and no larger than the eligible count
adoption_period Zero-based valid period
eligible_units Optional unique valid positions; default is every unit

For eligible set \(E\), each eligible unit has marginal probability \(n_{treated}/|E|\). Metadata contains treated_units, eligible_units, adoption_period, and the unit-aligned propensity_scores vector.

4 BinaryLogitAssignment

Code 
show_signature(pps.BinaryLogitAssignment)
BinaryLogitAssignment(adoption_period: 'int', intercept: 'float' = 0.0, observable_coefficients: 'Sequence[float]' = (), unobservable_coefficients: 'Sequence[float]' = ()) -> None

Draws independent eventual-treatment indicators using

\[ P(D_i=1\mid X_i,U_i)= \Lambda(\alpha+X_i^\top\beta+U_i^\top\gamma). \]

Parameter Default Contract
adoption_period Required Zero-based valid period
intercept 0.0 Finite scalar
observable_coefficients () One finite coefficient per observed feature
unobservable_coefficients () One finite coefficient per latent feature

The coefficient counts must exactly match AssignmentContext. Unlike fixed-size randomization, the treated count is random and all-treated or all-control draws are possible in small/extreme designs. Metadata contains the linear predictor, sigmoid probabilities, realized treated units, coefficient vectors, and adoption period.

5 StaggeredAdoption

Code 
show_signature(pps.StaggeredAdoption)
StaggeredAdoption(adoption_times: 'Mapping[int, int]') -> None

Accepts a mapping {unit_position: adoption_period} and constructs absorbing treatment. Units absent from the mapping are never treated. The mapping is copied at construction. Invalid unit or time positions raise ValueError.

6 GeneralizedPropensityAssignment

Code 
show_signature(pps.GeneralizedPropensityAssignment)
GeneralizedPropensityAssignment(adoption_periods: 'Sequence[int]', intercepts: 'Sequence[float]' = (), observable_coefficients: 'Sequence[Sequence[float]]' = (), unobservable_coefficients: 'Sequence[Sequence[float]]' = ()) -> None

Maps each unit to one adoption cohort or never treated. For \(G\) supplied adoption periods, coefficient rows correspond to those periods in caller order. Never treated is category G with normalized logit zero.

Parameter Shape Contract
adoption_periods (G,) Nonempty, unique, valid zero-based periods
intercepts (G,) Finite; omitted means zeros
observable_coefficients (G,K_x) Finite; omitted means zeros
unobservable_coefficients (G,K_u) Finite; omitted means zeros

Probabilities use a stable row-wise softmax. One uniform draw maps each unit to a category; treatment is one from the realized adoption period onward.

Metadata keys:

Key Shape or value
generalized_propensity_scores (N,G+1); rows sum to one
cohort_linear_predictors (N,G)
assigned_categories (N,); G denotes never treated
adoption_times (N,); never treated uses n_periods
adoption_periods (G,)
never_treated_category Integer G
coefficient/intercept keys Normalized NumPy arrays used in the draw

7 ConstantEffect

Code 
show_signature(pps.ConstantEffect)
ConstantEffect(value: 'float' = 1.0) -> None

Returns value * context.treatment. value defaults to 1.0 and must be finite. Metadata records kind="constant" and the value.

8 LinearRampEffect

Code 
show_signature(pps.LinearRampEffect)
LinearRampEffect(slope: 'float' = 0.2) -> None

For adoption time \(G_i\), returns

\[ \tau_{it}=s\max(t-G_i+1,0)W_{it}. \]

slope defaults to 0.2 and must be finite. The effect supports staggered absorbing adoption because event time is unit specific. Nonabsorbing treatment raises through context.adoption_times.

9 CallableOutcomeModel

Code 
show_signature(pps.CallableOutcomeModel)
CallableOutcomeModel(function: 'OutcomeCallable', name: 'str' = 'callable_outcome') -> None

Adapts a plain callable (SimulationContext, Generator) -> matrix | ComponentDraw to OutcomeModel. Matrix results are wrapped in ComponentDraw with kind=name; a returned ComponentDraw is preserved. Final shape and finiteness remain the simulator’s responsibility.
