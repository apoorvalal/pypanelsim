Canonical design API

Shared configuration, reusable factories, one-draw functions, and outcome components

Code 
import inspect

import pandas as pd
import pypanelsim as pps

1 CanonicalPanelConfig

Code 
print(f"CanonicalPanelConfig{inspect.signature(pps.CanonicalPanelConfig)}")
CanonicalPanelConfig(n_control: 'int' = 160, n_treated: 'int' = 40, n_pre: 'int' = 40, n_post: 'int' = 10, effect_slope: 'float' = 0.2, noise_variance: 'float' = 0.36) -> None
Field Default Contract
n_control 160 Positive never-treated count
n_treated 40 Positive treated count
n_pre 40 Positive common pre-period count
n_post 10 Positive post-period count
effect_slope 0.2 Finite event-time slope
noise_variance 0.36 Finite nonnegative observation-noise variance

Properties n_units, n_periods, and dimensions derive the generic panel shape. Canonical factories put controls first, treated units last, and begin treatment at n_pre.

3 One-draw functions

4 Canonical outcome components

These classes can also be composed outside the canonical factories:

outcome_components = [
    pps.ClassicFactorOutcome,
    pps.WeakFactorOutcome,
    pps.SyntheticControlOutcome,

    pps.TimeSeriesOutcome,

All implement generate(context, rng) -> ComponentDraw. Factor components store unit-aligned loadings and factor paths in metadata. Synthetic designs add active donors and donor weights. Time-series designs store the latent process before observation noise. Metadata arrays are diagnostic truth and become read-only in the final dataset.

5 Named construction

Code 
print(f"make_canonical{inspect.signature(pps.make_canonical)}")
print(f"available_canonical_designs{inspect.signature(pps.available_canonical_designs)}")
print(pps.available_canonical_designs())
make_canonical(name: 'str', /, **kwargs: 'object') -> 'PanelSimulator'
available_canonical_designs() -> 'tuple[str, ...]'
('classic_factor', 'factor_synthetic', 'mixed_factor', 'synthetic_control', 'time_series', 'weak_factor')

make_canonical(name, **kwargs) delegates to the global canonical registry. Unknown names and invalid factory parameters raise ValueError/TypeError from the registry or selected factory.

6 Compatibility aliases

PanelConfig aliases CanonicalPanelConfig; PanelData aliases PanelDataset. They remain for migration from the extracted panel_dgps module. New code should use the explicit canonical and dataset names.
