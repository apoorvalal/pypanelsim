Core API

Dimensions, contexts, datasets, simulation orchestration, and randomness

Immutable rectangular panel dimensions.

4 AssignmentContext

Code 
print(signature(pps.AssignmentContext))
AssignmentContext(dimensions: 'PanelDimensions', observables: 'FloatMatrix | None' = None, unobservables: 'FloatMatrix | None' = None, feature_metadata: 'Mapping[str, Any]' = <factory>) -> None

Immutable input to feature-aware assignment mechanisms. It owns read-only copies of observed and latent unit features. n_units and n_periods proxy the enclosed PanelDimensions, which keeps legacy assignments that only inspect dimensions operational.

6 Component protocols

The protocols are runtime-checkable but inheritance is optional.

class UnitFeatureModel(Protocol):
    def generate(self, dimensions, rng) -> UnitFeatureDraw: ...

class AssignmentModel(Protocol):
    def assign(self, context, rng) -> ComponentDraw: ...

class OutcomeModel(Protocol):
    def generate(self, context, rng) -> ComponentDraw: ...

class EffectModel(Protocol):
    def generate(self, context, rng) -> ComponentDraw: ...

All randomness must come from the supplied numpy.random.Generator.

7 PanelDataset

Code 
print(signature(pps.PanelDataset))
PanelDataset(outcome: 'FloatMatrix', treatment: 'FloatMatrix', untreated_outcome: 'FloatMatrix', treatment_effect: 'FloatMatrix', name: 'str', unit_ids: 'NDArray[Any] | None' = None, time_ids: 'NDArray[Any] | None' = None, metadata: 'Mapping[str, Any]' = <factory>, unit_covariates: 'FloatMatrix | None' = None, unit_covariate_names: 'Sequence[str] | None' = None) -> None

The immutable output of every simulation.

7.1 Constructor arrays

Field Shape Validation
outcome (N,T) Finite, nonempty, two-dimensional
treatment (N,T) Same shape; binary
untreated_outcome (N,T) Same shape; finite
treatment_effect (N,T) Same shape; zero where untreated
unit_covariates (N,K) Optional finite time-invariant covariates

The constructor enforces

\[Y=Y(0)+\tau\]

cell by cell. It copies arrays before making them read-only, so later mutation of caller-owned inputs cannot alter the dataset.

7.2 Identifiers and metadata

unit_ids and time_ids default to zero-based integer positions and must be unique. unit_covariate_names defaults to x1, x2, and so on; names must be unique and cannot collide with the long-form core columns. metadata is copied and recursively frozen for mappings, arrays, lists, tuples, and sets.

7.3 Properties

Property Meaning
shape, n_units, n_periods Panel dimensions
ever_treated Unit-level treatment mask
treated_units, control_units Integer row positions
is_absorbing Monotone treatment indicator
adoption_times First treated period or horizon sentinel
true_att Mean realized effect over cells with treatment == 1

true_att raises ValueError when the panel has no treated cells.

8 PanelSimulator

print(signature(pps.PanelSimulator))
PanelSimulator(name: 'str', dimensions: 'PanelDimensions', assignment: 'AssignmentModel', outcome_model: 'OutcomeModel', effect_model: 'EffectModel | UnitEffectCallable', feature_model: 'UnitFeatureModel | None' = None) -> None
Field Contract
name Nonempty design identifier

effect_model Object satisfying EffectModel, or a unit-effect callable
feature_model Optional object satisfying UnitFeatureModel

8.1 Pipeline

  1. Resolve one NumPy generator.
  2. Draw shared observed and latent features, if configured.
  3. Draw and validate binary treatment.
  4. Build SimulationContext.
  5. Draw and validate untreated outcomes.
  6. Draw effects and reject nonzero effects outside treated cells.
  7. Return PanelDataset(outcome=untreated+effect, ...).

Component metadata is namespaced under features, assignment, outcome, and effect. The simulator name and dimensions are stored under simulator.

A callable supplied directly as effect_model is wrapped in CallableUnitEffect. It receives SimulationContext, returns a scalar or an (N,) unit-effect vector, and is multiplied by the realized treatment matrix.

9 resolve_rng

Code

resolve_rng(*, seed: 'int | np.random.SeedSequence | None' = None, rng: 'np.random.Generator | None' = None) -> 'np.random.Generator'

Returns the supplied numpy.random.Generator after type validation or constructs numpy.random.default_rng(seed). Passing both seed and rng raises ValueError; passing a non-generator rng raises TypeError.
